# 奇异点附近 IK 稳定性测试 · 设计文档

## 1. 目标

对 FR3 七轴臂的**全部奇异类型**，用**三种逼近方式**，量化对比伪逆（pinv）与阻尼最小二乘（DLS）在奇异点附近的稳定性。

## 2. 实现形式

- 单个脚本 `scripts/benchmark_singularity.py`
- 风格与已有 `benchmark_ik_stack_poses.py` 一致：定义工况 → 采集 → 聚合 → 出图
- 不新增包，无需修改现有 `m2_ik/` 代码

## 3. 奇异工况定义

| # | 工况名 | 参数 | 扫描范围（奇异附近加密） | 物理说明 |
|---|--------|------|------------------------|---------|
| 1 | `wrist` | `q₅` | `[-2.0, -1.0, -0.5, -0.2, -0.1, -0.05, -0.02, -0.01, 0, 0.01, 0.02, 0.05, 0.1, 0.2, 0.5, 1.0, 2.0]` | q₅=0 时关节 4、6 轴共线 |
| 2 | `elbow` | `q₄` | 从 `-2.5` 线性扫到 FR3 **q4 上界** `-0.0698` 前留余量，36 步 | 手臂接近伸直（Franka 肘关节主要为 `q4`） |
| 3 | `shoulder` | `(q₁, q₃)` | 在 q₁=0, q₃=π/2 附近联合扫描，各取 9 步 = 81 组合 | 第 1、3 轴对齐 |
| 4 | `boundary` | `q₆` | 从 `2.0` 扫到 FR3 上限 `3.7525`，20 步 | 接近关节限位 |

## 4. 三种逼近方式

| 方式 | 实现 | 适用工况 |
|------|------|---------|
| **A 关节空间扫** | 以参考姿态为基，修改奇异参数 → FK → 目标位姿 → IK 求解 | 全部 4 种 |
| **B 任务空间扫** | 取奇异参数处的姿态为目标，沿末端位置直线穿越奇异 | 手腕、肘部、肩部 |
| **C 随机批量** | 奇异参数 ± 小邻域内随机采样初值，统计成功率 | 全部 4 种 |

## 5. 采集指标

每次 IK 求解记录一条：

| 字段 | 类型 | 说明 |
|------|------|------|
| case | str | `wrist` / `elbow` / `shoulder` / `boundary` |
| sweep_mode | str | `joint` / `task` / `random` |
| singular_dist | float | 距奇异点的度量（如 `|q₅|`） |
| method | str | `pinv` / `dls_0.02` / `dls_0.05` / `dls_0.2` |
| converged | bool | `final_err < tol` |
| iters | int | 迭代次数 |
| final_err | float | 最终任务误差范数 |
| max_dq_norm | float | 全程迭代中最大 ‖Δq‖（与 `inverse_kinematics` 等价单步更新并统计） |
| manipulability | float | `√det(JJᵀ)` 在奇异参数处的值 |

## 6. 可视化

按三种逼近方式各出一张 **4 行 × 3 列** 的图（四种工况为行；列为收敛率、最大 ‖Δq‖、可操作度），多方法曲线叠加。

输出到 `outputs/singularity_benchmark/sweep_{joint,task,random}.png`，同时输出完整 CSV。

## 7. CLI 参数

```
--damping 0.02 0.05 0.2     # 默认 [0.02, 0.05, 0.2]
--tol 7e-4
--max-iters 500
--step-scale 0.55
--seed 20260514
--out outputs/singularity_benchmark/
```
